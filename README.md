# Spam Email Classifier

## Project Overview
This project classifies text messages as Spam or Ham using machine learning.

## Features
- Uses TF-IDF Vectorizer
- Trains a Naive Bayes classifier
- Predicts whether a new message is spam or not
- Beginner-friendly NLP project

## Technologies Used
- Python
- Pandas
- Scikit-learn

## How It Works
1. Load labeled spam/ham messages
2. Convert text into numerical features using TF-IDF
3. Train a Naive Bayes model
4. Test model accuracy
5. Predict new messages
